# 论文讲解与中文表达规范（生成前必读）

> 本文件约束**出现在 PPT 上的文字**，不是论文笔记、审稿清单或演讲稿。用户已有专业基础，但未必读过本文。优先保证看图即可理解核心机制；不要用审稿术语充当讲解。与论文事实不一致时，始终以原文为准。

## 1. 两层语言必须分开

内部研究层可使用“待检验主张、作用路径、替代解释、证据强度、评估协议、不可识别性”等术语，组织审查与来源核实。**投影表达层**只能保留听众理解方法及证据所需要的信息，改写成研究对象、具体操作、观察结果和限制条件。

- 内部：`待检验主张：汇总表示是否保留跨标志物条件信息`。
- 投影：`隐藏 CD8 的全部图像后，模型能否利用其他蛋白恢复其空间分布？`
- 内部：`分解注意力降低注意力连接复杂度`。
- 投影：`先比较同一位置的不同蛋白，再沿空间位置交换信息，避免直接计算所有“蛋白×位置”之间的关系。`
- 内部：`整体性能不能归因于独立模块`。
- 投影：`这组实验比较的是完整模型与基线，尚不能单独证明 ESM-2 的贡献。`

上面是**表达方式示范**，不是所有论文都要展示这些生物信息学细节。审稿术语仅在审查本身是幻灯片主题时才写在屏幕上。

## 2. 先建立听众的认知顺序，再决定页数

论文精讲按理解难度而不是强行套每篇 4–5 页：

1. **任务与动机**：一个真实/标注的示意输入、输出是什么；现有方法卡在什么条件上。若听众不清楚“蛋白通道”“标签”是什么，在方法页之前用一行解释。
2. **一句核心思想**：作者采用哪种表示、操作或训练目标，针对哪个困难。不是罗列模块，更不是宣传语。
3. **方法全景**：可追踪的输入 → 编码/交互 → 训练或使用 → 输出。区分训练与推断；每个箭头代表数据流、监督还是参数更新。
4. **关键机制放大**：只选 1–2 个决定性设计；在同一具体例子上说明输入对象、计算、共享变量、输出和它为什么需要这样做。不能只有“模块 A → 模块 B”。
5. **证据和判断**：结果图的横纵轴、比较条件、主要结果，以及证据只能支持到哪里。关键对照优先于无关的多组指标。

一般论文可用 4–5 页；机制较复杂、论文含多个尺度或需比较多项实验的，可以 6–10 页或按用户指示。**多页不是多段审稿文字**：增加的页面必须解决新的理解障碍。

### 机制页的强制检查

每个重要模块至少要能从画面找到四项：`接收什么`、`如何处理`、`得到什么`、`为什么需要`。对自监督方法还须指出遮挡/标签/损失分别在哪里；对预测方法指出训练期与推理期可见信息有何不同；必要时标记梯度会更新哪些组件。

## 3. 中文必须像中文学术讲解，而不是英文直译

**具体对象 + 动词 + 条件/结果**，优于“名词串 + 抽象动词”。

| 避免的句式 | 更自然且可理解的写法 |
|---|---|
| 跨面板学习组织的多尺度表示 | 不同实验检测的蛋白不完全一致，模型仍尝试学习可复用的组织特征 |
| 从身份感知 token 到多尺度表示 | 模型如何把蛋白身份和局部图像合成一个 token |
| 以汇总表示连接编码与解码 | 每个位置的汇总 token 整合可见蛋白信息，供解码器预测被遮挡的蛋白 |
| 支持跨蛋白条件预测 | 隐藏一种蛋白后，利用其余蛋白的信号预测它的空间分布 |
| 为下游任务提供读出接口 | 按细胞或组织区域汇总 token，再训练细胞分类或患者预测模型 |
| 方法的作用路径 | 这一步为什么有用 |
| 缺失标志物重建 | 预测实验中未检测或被遮挡的蛋白信号（两种场景不可混同） |
| 能否在预训练未见的队列上直接使用 | 不用这个队列训练，模型在新队列上还能预测得准吗 |
| 响应预测与外部生存关联回答不同问题 | 一个实验预测治疗响应，另一个检验生存风险相关性；不能把两者当作同一验证 |

尽量少用以下**无实体的搭配**：赋予通道语义、限制注意力连接、状态接口、组织级接口、作用路径、能力闭环、赋能、端到端统一范式、实现跨尺度赋能、知识写入表示、持续校准对象、汇总表示承载信息。这些词不是禁词，只有当它们指向已清楚解释的对象/计算时才可使用。

保留通用英文专业名称（Transformer、Token、Attention、scRNA-seq、MAE、AUROC 等），首次出现说明具体含义。不要为了“全中文”硬译术语；“读出”在神经科学或模型 readout 的确切意义下可用，但优先直接写“分类器/预测头/聚合后的向量”。

**标题优先是陈述句或可回答的具体问题**；不要把“研究背景、方法创新、实验结果、核心贡献”本身当成信息标题。删除“本页展示、下一页将、可以看出、这里我们、这为……奠定基础”之类的空话。

## 4. 页面写作模板（不是固定标题栏）

- **封面核心想法**：`作者将 [实际观测] 与 [必要先验] 组合成 [表示]，通过 [关键机制/训练任务] 学习 [具体关系]，用于 [论文实测的任务]`。若没有明确的因果实验证据，用“用于/旨在”，不要写“证明实现”。不超过两句；不能把 6 个专业名词挤在一句。
- **方法标题**：`模型在同一位置比较不同蛋白，再跨空间位置交换信息` 比 `双轴多尺度交互机制` 更好。
- **机制注释**：`将每个蛋白图像切成 8×8 的块，与蛋白序列向量相加` 比 `多模态编码与语义注入` 更好。数字、参数与对象必须与原文一致。
- **实验标题**：`完全隐藏一个蛋白通道时，预测与实测的相关系数仍为 0.70` 比 `汇总表示具有泛化性` 更明确（仅在原文支持该条件和结果时使用）。
- **局限**：`该实验只有重建相关性，没有测试药物干预后的变化` 比 `结论范围有待验证` 更有用。

## 5. 写完必须进行“去翻译腔”复写

草稿完成但尚未写入规格 JSON 前，逐页执行：

1. **删标签**：将“待检验主张/怎样检验/观察与结论/作用路径”等内部审核栏目替换成与本页图有关的具体简短问题或结论；如果标签没有增加理解，直接去掉。
2. **补对象**：圈出“它、这一机制、能力、表示、信息、作用”等无指代词，改成明确的蛋白、细胞、Token、损失、编码器等，且不增加未核实的机制。
3. **拆长句**：一句只讲一个主因果关系。跨两次以上“通过/从而/进而/使得/以实现”的句子拆开；不为了降低字数而牺牲准确性。
4. **具体例子**：方法复杂时选一个真实或明确标注“示意”的对象贯穿输入、机制、训练和结果。不要把示意例写成论文使用的真实数据或实验结果。
5. **事实审查**：对每一句效果性陈述问“原文哪个实验直接支持”。将“能够/证明/必然”改成证据真正允许的陈述，保留数据划分、基线及解释限制。
6. **投影审查**：在 16:9 整页预览里不借助备注，从左到右能说清一条输入→运算→输出的链；每张图的高亮位置能与旁边文字一一对应。

**退稿条件**：核心想法不能脱离模型缩写独立解释；方法只有模块名而无操作；实验只有数字没有对照和样本条件；不超过两页就连续重复同一主张；明显以审稿模板词堆满页面。退稿应改内容，不以缩小字体处理。

## 6. 用已有 PPT 做回归测试

建议以用户给出的 `1106.pptx` 为人工回归样本（文件不加入仓库）：

- 第一篇 VirTues：旧封面“把每个蛋白通道的图像块与蛋白序列表示相加，再交替学习标志物关联与空间结构”事实方向基本对，但未说明两个 Attention 在**同位置跨蛋白 / 同蛋白跨位置**上分别做什么。改写应把这个对比可视化。
- 方法页“汇总 token”“逐通道解码”要画出：可见蛋白 → 汇总 Token → 目标蛋白解码器 → 被遮挡信号。仅写“连接编码与解码”不及格。
- 结果页“待检验主张/怎样检验/观察与结论”不必一律显现。可以将原图放大，旁边直接写“隐藏什么、与谁比较、得到多少、不能证明什么”。
- AIVOs 是**综述提出的框架**，不要把其中引用的 GARMEN、ODFormer 实验当成 AIVOs 本身的训练和验证。

这些回归样本验证的是**语言与讲解逻辑**。若没有重新生成和逐页渲染，不应声称对视觉效果完成验收。
