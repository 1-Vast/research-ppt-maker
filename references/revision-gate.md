# 论文 PPT 的结构性改稿闸门（生成质量回归）

本文件针对“旧版被指出讲解结构有问题，新版只是改词/移除编号”的失败模式。用于**明确要求重做研究故事、模型图或实验图**的任务；如果用户仅要求小范围措辞或格式修改，不应用“新旧图片完全相同”否决正确的小修。

## 一、任务开始前，先判断改动属于哪一级

| 改动级别 | 用户意图 / 失败模式 | 通过标准 |
|---|---|---|
| L1 文案局部修改 | 修错字、替换术语、删除遮挡标签 | 目标对象修复、不误改别页即可 |
| L2 讲解质量重写 | 背景没有发展脉络、模型图看不懂、创新未区分主次、实验讲不清楚 | **重建内容故事线和图像选择/布局**，并提供改动前后的对应证据 |
| L3 整套重构 | 论文类型、目标受众、信息组织或参考布局整体错误 | 可以重排、增删页和图，按重新生成完整课件验收 |

当用户要求 L2/L3，禁止把 **“改标题 + 同一张图 + 原来位置 + 换审稿栏目名”** 当作完成。只有实质验证后才交付。

## 二、先出内部「故事板」，再运行 PPT 构建

在 `work/storyboard.json` 或等价文件，**按每篇论文**记录：

- `paper_type`: original-method / experiment / review / benchmark / theory；
- `field_story`: 测量场景、代表技术进展、当前新条件、核心矛盾、本文切入点；每项来源可追溯；
- `one_sentence_takeaway`: 不依赖模型缩写的核心想法；
- `core_contributions`: 每项贡献的对象、具体设计、作用、原文位置、对应下游任务/实验证据；
- `method_map`: 输入、编码、核心交互、训练/推断、输出；在完整模型图中可定位；
- `slide_plan`: **为什么必须有这一页、听众在此处新增理解了什么、选哪张图、图讲的是否恰好是该页结论**；
- `visual_evidence`: 精确到 figure 和 panel 的出处；有定量结论则对应结果图或真实数值表；
- `omissions`: 删除与辅助化的模块及其理由；复杂创新不允许只给三个标签不解释。

这些是制作前的内部证据，不强制添加到 PPT，也不作为额外交付。

**停止规则**：如果故事板只依次列出“问题一、二、三 ↔ 创新一、二、三”而没有说明领域进展和中心矛盾，或总模型图不显示真正的信息流，**不得开始 PPT 排版**，先重写故事板。

## 三、成品出现以下问题必须返工

1. **旧内容残留**：删掉 A/B/C 图上标注后，图注仍写“A/B/C 是本次讲解标注”，或解释仍指向已经不存在的箭头/框。这是独立的跨对象一致性错误，不是风格意见。
2. **创新内容复制**：为满足“补一个创新点”，直接复用上一创新的 before/after/why。即使标题不同也无效。每项创新至少能写出一条**与其他项不同**的设计操作和受益对象。
3. **图证错配**：标题说“PCC 提升”，可见主图却是架构图；可列架构背景，但真正对应的实验结果图或数值表必须出现。
4. **图像充当占位符**：全景模型图虽有来源，却缩到无法辨识；旁边几段文字不指向图的具体模块或箭头。
5. **综述伪装统一实证**：综述中的 UR/VI/仿真/校准作为提出的框架展示；引用研究只能证明各自子任务，不得拼成同一研究已实现的完整闭环。
6. **机械语言修复**：仅把“待检验主张”换成“先……”，没有补具体实验条件、可见指标和读图关系。

## 四、自动检查：报告候选问题，不伪称已做科学验证

运行：

```bash
python "SKILL_DIR/scripts/review_deck.py" "OUT/主题-完成版.pptx" --output "OUT/work/review.json"
python "SKILL_DIR/scripts/review_deck.py" "OUT/主题-完成版.pptx" --baseline "INPUT/旧稿.pptx" --output "OUT/work/revision-review.json"
```

输出包含：

- `duplicate_explanation`: 同页长句在多个文字对象中重复（提示复制说明或挤占空间）。
- `orphaned_annotation_reference`: 图注还在说明自加 A/B/C 标注，但文字对象中已没有完整的一组；图片本身可能含字母，因此需视觉核查。
- `mixed_architecture_and_metric_evidence`: 架构图的语言与实验指标并存；**只提示图证可能错配**，不能断言确有错误。
- `revision_comparison`: 新旧页数、文本变化、图片二进制哈希和位置、整体形状几何；所有图片完全不变且改稿要求是 L2/L3 时必须人工证明这不是换词式改稿。图片本来合适时允许保留。

**此脚本不是语义模型、不是 OCR，也无法识别图片内的论文内容；不能根据“0 个预警”宣布论文讲解通过。**

## 六、人工完成条件

最终渲染每一页（不是只看提取文字），用原图与所选论文版本对照。完成单个代表性结果页的读图模拟：给一个未读过论文但具备相关背景的人展示该页，是否能指出实际比较了什么、结论来自图中的哪组数据、还有什么没有证明。没有实际观众评测时只可称“内部可读性审核”，不得声称“经听众测试”。
