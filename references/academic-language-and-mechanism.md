# 组会中文表达与模型机制审校

本文件针对最终投影文字，而不是内部论文笔记。组会语言应当**正式但自然、直观但不失精确**。不要通过增加术语来代替解释，也不要把所有通俗表达一律视为错误。用户现有的页面布局已被认可时，优先修文案和必要的信息连接，不擅自重构布局。

## 1. 三项独立检查

1. **学术语体**：去除没有实际对象的口语提示，如“测谁”“看这条路”“另丢弃”“看×”；改成对数据、条件或计算操作的直接说明。
2. **首次定义**：Mask Token、Summary Token、s(p)、训练/推理、可见 Token 等术语首次出现时，明确其定义、产生位置及用途。不能只把“mask 查询”改成“Mask Token”便认为解释完成。
3. **机制忠实度**：解码器可访问什么、不可直接访问什么，哪些值来自其他蛋白、哪些来自目标通道，损失对哪些像素计算，都要与原文核对。绝不能为了通顺而删除改变机制含义的条件。

## 2. 典型错误与改写方向

| 需要审查的措辞 | 投影时更合适的表达 | 特别注意 |
|---|---|---|
| 蛋白身份说明“测谁” | 蛋白序列表示用于标识对应的蛋白 | 序列向量不等于实测表达量 |
| 图像与蛋白分别投影 | 图像块特征与蛋白序列向量分别投影至相同维度 | 指出向量的真实来源 |
| 编码与局部汇总 | 编码器整合跨蛋白及跨空间的信息 | Spatial Attention 后汇总表示不一定只含局部信息 |
| 带蛋白身份的 mask 查询 | 表示目标蛋白被遮挡图像块的 Mask Token，并加入目标蛋白身份信息 | 不能删掉身份条件 |
| 每位置 s(p) | 每个空间位置的汇总表示 s(p)，其中 p 表示 Patch 位置 | 首次定义符号，下次可用简写 |
| 另丢弃 0–25% 通道 | 另随机移除一定比例的完整蛋白通道（按原文注明范围） | 区分图像块遮挡与整通道移除 |
| 整通道隐藏时看这条路 | 目标蛋白整通道遮挡时，其他蛋白的观测信息如何传递给解码器 | 讲清解码器的信息访问限制 |
| 看“×”：整通道隐藏 | 图中的“×”表示整通道遮挡条件 | 核对真实图例 |
| 重建误差更新模型 | 用重建损失更新可训练的投影层、编码器与解码器 | 核对参数更新范围 |
| 训练覆盖所有像素；评估只统计遮挡位置 | 分别注明训练损失与评估指标对应的像素范围 | 训练与评估不自动相同 |

例句只是中文表达参考。任何具体数字、Masking 比例、参数量和路径都必须再次核对该论文版本。

## 3. Summary Token 等信息瓶颈的讲法

先明确架构，随后描述训练任务的作用，最后报告实验证据，不能将三者合并为一个保证。

- 架构事实：编码器中，Summary Token 与可见蛋白 Token 交互；解码器接收目标通道的可见编码、目标相关 Mask Token 及 Summary Token，按论文设定不直接读取其他蛋白的独立编码 Token。
- 机制推断：目标通道完全遮挡时，其余蛋白观测信息必须经可访问的汇总表示等允许路径传递；如果 Summary Token 经空间注意力更新，其内容可能带有跨位置上下文。
- 验证边界：这种设计提供信息传递路径和优化压力，不等于仅凭架构已经证明模型“学习真实跨蛋白因果关系”。要根据整通道重建结果及必要对照评价实际利用程度。

讲解图至少让观众知道**目标通道部分可见时与完全不可见时，解码器输入的区别**。不要把“目标通道没有任何可见像素”错误表述为“模型不具备该蛋白的身份信息”。

## 4. 屏幕上保留必要的专业性，但不塞审稿语言

- 标题写明确的科研事实或问题，不要用“作用路径、赋能、读出接口”充当内容。
- 对自监督预训练说明真实监督信号来源；“不使用细胞类型标签”不等于无监督信号。
- 保留必要的数学符号，但每个符号在同页或前一页必须有明确指代。
- 一页有六个模块时，保留已经被认可的上下布局，不因语言审核自动重绘。只在原结构遗漏机制条件时补上一句必要说明。
- 每页完成“语体—术语—科学关系”三遍审查，投影文字不能靠演讲者补上决定机制含义的限制。

## 5. 与自动检查的关系

`lint_deck_language.py` 可提示部分口语化和审稿式短语，但没有能力确认术语是否已定义、某个 Mask Token 是否真的包含蛋白身份、Summary Token 是否是必要信息通路。所有候选须人工结合原文与最终渲染图判断。脚本无警告不代表科学或语言验收通过。
