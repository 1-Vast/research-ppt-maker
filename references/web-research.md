# 网上科研展示方法：已核查来源

访问日期：2026-10-24。以下页面均实际获取并阅读正文；建议经归纳后用于技能，未将一般建议升级为不可变规范。搜索引擎曾返回验证页或无关结果，未引用这些结果；改用出版社全文和官方教学资源，并通过 Crossref 核对组会文章 DOI。

## 1. Naegle，2021：幻灯片本身应当传达信息

**Ten simple rules for effective presentation slides**，PLOS Computational Biology。

- DOI：https://doi.org/10.1371/journal.pcbi.1009554
- 全文：https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1009554
- 提炼：一页一个信息；标题承担主要结论；有效图形；减少认知负荷；论文多面板图按问题拆开；准确引用；观众错过口头解释也应能辨认页面要点。
- 技能落实：信息标题、局部图放大、短注释、备份页、可读性检查。文中“一页一分钟”不写成固定页数公式。

## 2. Michael Alley / Penn State：Assertion–Evidence

- 官方入口：https://www.assertion-evidence.com/
- 正式教程：https://www.craftscicom.org/ae_tutorial.html
- 研究生展示示例索引：https://www.assertion-evidence.com/research_models.html
- 提炼：围绕信息/主张而非主题名组织；用视觉证据支撑；默认项目符号容易挤占图形空间，导致标注过小。
- 技能落实：信息标题 + 主图证据；不把论文段落改成项目符号就视为完成。方案页允许问题标题，不把未经验证的设想写成结果。
- 范围：读取了教程正文和示例索引说明，未声称观看全部视频或审阅示例每页。教程提及把次要细节放备注，本技能按用户要求改用必要的备份页，不生成讲稿。

## 3. Golden 等，2021：组会应服务当前目标

**Ten simple rules for productive lab meetings**，PLOS Computational Biology。

- DOI：https://doi.org/10.1371/journal.pcbi.1008953
- 全文：https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1008953
- 基于 University of Massachusetts 研究组实践，强调明确会议目标、参与者需要、角色和灵活调整。
- 技能落实：先判断本次是论文理解、结果讨论还是方案决策；进展页说清变化和障碍；结尾给具体讨论问题。本文讨论组会组织，不把它当作字体/版式实验依据。

## 4. Bourne，2007：少而清楚，保持逻辑

**Ten Simple Rules for Making Good Oral Presentations**，PLOS Computational Biology。

- DOI：https://doi.org/10.1371/journal.pcbi.0030077
- 全文：https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.0030077
- 提炼：适配受众，减少材料，保留核心信息与逻辑线，图形数量服务表达。
- 技能落实：必要背景、主线/备份区分、图证与结论对齐。口头训练及录音建议不扩展成本技能的文稿交付。

## 证据和设计判断的边界

以上支持“清晰信息、有效图证、目标导向”。字号范围、页面配方和本地风格建议是制作起点，需根据场地和渲染调整，不宣称是上述论文证明的统一最优值。用户要求更新方法时再检索，普通 PPT 制作不强制重做本次网上调研。
