# 科研内容到页面

## 根据任务取舍

论文汇报不必复述论文目录。背景讲到足以建立研究动机：先说明实际任务与评价目标，再选最相关的已有路线，交代代表工作已做到什么、具体还有什么条件或能力未解决，最后落到本文要检验的缺口。相关工作应在方法之前建立，不用本文结果或一句“传统方法不足”替代；保留前作真实成果，不为衬托本文捏造失败。有限页数优先保留这条前因，再合并重复的方法与创新说明。DOI/标题定位、原文阅读与分层图解见 [paper-research-and-explanation.md](paper-research-and-explanation.md)。

进展组会要让同组成员知道变化：上次卡在哪里，本次新增了什么证据，下一步该作什么选择。失败结果可以是主证据，写清排除了什么解释，而不是隐藏在“后续工作”后面。

调研/开题用统一比较维度组织文献，例如输入、可用监督、模型作用、评价协议、局限和迁移条件。不要每篇论文都重复同样三页摘要，也不要拼一张无法阅读的大表。按需要拆为概览和重点机制。

## 页面配方，按内容选用

| 内容 | 直观表达 | 最小必要信息 |
|---|---|---|
| 任务定义 | 一个具体输入/输出例子或映射 | 预测对象、已知信息、输出含义 |
| 现有缺口 | 并列对比或问题链 | 已能做到什么、尚未满足的能力、适用条件或实际代价 |
| 方法总览 | 主路径与必要分支 | 输入、关键变换、输出；训练/推断区别 |
| 模块创新 | 前后对照或局部放大 | 原方案、改变、预期/已验证作用 |
| 结果 | 放大的关键图或精简表 | 指标方向、基线、协议、观察、结论范围 |
| 消融 | 模块移除对比 | 固定条件、去掉什么、性能变化 |
| 局限 | 证据与边界并列 | 结论成立条件、不能推出什么 |
| 下一步 | 小型决策图或验证路线 | 假设、实验、成功/失败判据、需讨论事项 |

配方不是页数配额；一页可以合并简单任务和动机，复杂方法可能需要总览加数页局部。

有限页数内按论证分配篇幅：背景建立具体缺口；方法展开关键约束如何产生；创新分析为何作此选择、相对什么方案有差异以及代价；少量实验对应核心主张。创新不必单独占页。去掉标题后若两页仍是同一套模块描述，合并重复内容，把空间留给缺失的背景、直接比较或机制解释。原图、公式和文字各自承担不同信息，避免整页成为原图旁的同义复述。

背景不能只列模型名、年份和训练规模。对最相关的前作说明“用什么信息/目标做什么、已经实现什么、在哪个条件或目标上仍有研究空间”；至少把一个关键设计与前作放在同一维度比较。区分原文已证明的不足与本文提出的新假设：未显式优化某能力不等于完全不具备该能力，换一种目标也不自动意味着胜过旧方法。任务间指标不可比时只比较设计，不拼性能排名。

正文页之间应承接具体问题，并说明为何需要下一步；连接体现在具体对象与问题的承接，不靠在页尾机械添加“因此”或“下一页”。例如“已有工作未显式监督哪种能力 → 本文构造什么目标 → 目标怎样作用于表示 → 用什么任务与对照检验”。结果前至少交代样本来源、输入/输出、是否还需下游训练、基线与指标所回答的问题；范围按理解选用结果的必要程度控制，不把实验背景扩成整页数据集清单。结论应回到最初问题，讨论边界不能挤掉主要贡献的解释。

## 长段文字如何改

原始材料：“模型对 Reference 和 Query 复合物分别编码，得到包含蛋白环境的配体表示，池化后求差，预测相对亲和力，并交换输入进行数据增强。”

可拆为：

1. 方法总览：两个有明确标签的复合物输入，共享编码器，两路池化，在“表示求差”处汇合，输出 Δ亲和力。用短注释说明共享参数。
2. 关键机制：放大输入交换与差值变号的对应关系，说明其约束。公式和符号方向须按实际来源核对。

这比在整张原图右侧塞入长段文字更容易追踪。若原图已足够清晰，保留它并加少量相邻标注，不必重复重画。

## 科研证据检查

- 明确数据集、划分、样本/重复、评价协议、指标方向和基线。报告自己的实验时保留实际运行与输出来源。
- 少样本 support 数量、未见靶标划分、冷启动/随机划分等可能决定结论，应在结果附近标注。
- 区分绝对提升、相对提升和百分点。例如 20% 到 30% 是 +10 个百分点或相对 +50%。
- 每个醒目数字附近注明相对谁、指标含义与方向；不能依赖另一个数字的说明或远处页标题来消除歧义。必要时交代样本单位及聚合口径，不把细胞数、聚合表达谱数、受试者数等混作同一数据规模。
- 区分计算筛选、功能实验、外部验证和临床效果；相关性、预测提升和机制因果不能互换。
- 生信图保留条件、图例和量纲：UMAP 不代表谱系因果，注意力图不自动等于机制解释；AUROC、AUPRC、IC50、ΔΔG 等按当前任务准确解释，不套万能结论。
- 引用紧邻被支持的图或结论，至少可追溯到作者/年份及图号或 DOI；原图、重绘、改绘和自有实验区分清楚。
- 给出 DOI、标题或项目描述时，主动检索完成解释所需的原文、背景和相关材料；范围以支撑 PPT 为准，不擅自扩成全面文献调研或新的科研实验项目。
