# 视觉系统：Claude 式克制美学

目标气质：像一份排版考究的研究简报，而不是营销模板。温暖的中性底色、单一陶土色强调、衬线标题、宽松留白和细线分隔；内容和证据是页面主角，装饰几乎为零。用户给了模板时以模板为准，只借用这里的层级、留白和配色克制原则。

`scripts/build_deck.py` 已实现以下规范；手工或扩展制作时照此执行。

## 配色

| 名称 | 色值 | 用途 |
|---|---|---|
| canvas | `#FAF9F5` | 页面底色（暖象牙白） |
| panel | `#F0EEE6` | 浅色块：例子、公式、边界说明、标题页右栏 |
| white | `#FFFFFF` | 流程卡片底色 |
| hair | `#E0DDD3` | 细线、卡片描边、表格行线 |
| ink | `#141413` | 标题、强调正文 |
| ink2 | `#3D3C38` | 正文 |
| muted | `#7A786F` | 出处、图注、次要标签 |
| faint | `#BDB9AE` | 未激活的进度条项、对照组条形 |
| clay | `#D97757` | 唯一强调色：本文、关键步骤、叙事箭头、编号 |
| clay_deep | `#B5583A` | 小号陶土色文字（栏目页眉、强调词），保证对比度 |
| clay_tint | `#F6E7DE` | “本文/待解决问题”底色块、表格中本文所在行 |
| slate | `#5E7A94` | 前作、以往做法 |
| olive | `#6B7F4E` | 证据或已验证结果（少用） |

- 语义固定：陶土色 = 本文，石板蓝 = 前作，灰色 = 对照或背景。整套同一对象同一颜色。
- 一页里陶土色只给最重要的一两处。图表只把本文一组设为陶土色，其余用 faint 灰，不要彩虹配色。
- 不用渐变、阴影卡片、霓虹色或纯黑底。唯一的阴影是标题页首页截图下的柔和投影。

## 字体

| 角色 | 字体（按顺序回退） | 默认字号 |
|---|---|---|
| 标题 | Noto Serif SC SemiBold → 华文中宋 → 宋体 | 封面 36 pt，内页 28 pt |
| 导语、原题、待解决问题 | Noto Serif SC → 华文宋体 → 宋体 | 16–18 pt |
| 正文、标签 | 微软雅黑 → 等线 | 正文 13–15.5 pt；标签 12 pt |
| 公式 | Cambria Math（中文回落到正文字体） | 18 pt |
| 页脚出处、图注 | 微软雅黑 | 10–10.5 pt |

- 构建脚本自动选用本机已安装的第一个字体。成品若要在别的电脑放映，确认对方有 Noto Serif SC，或另附 PDF。
- 中文文字必须标记 `lang="zh-CN"`（脚本已做），否则 PowerPoint 不执行中文避头尾规则，会出现行首的“；）。”。
- 标题用 `\n` 手动断行，避免把词拆开；避免只剩一个字的末行，出现时删改几个字即可。
- 用户允许字号略小时，优先启用 `compact_text`，保留标题、正文与图注的层级。当前构建脚本正文下限 13 pt；自定义布局的**次要说明**经投影渲染检查后可控制在 12–13 pt，关键解释一般保留 13–15 pt。不能为了减少页数降低原始图的可读性；核心内容放不下先删次要实验或合并重复页。
- 制作库的 px 与 PowerPoint 的 pt 不同，以实际渲染为准。技术缩写首次出现时配一句短定义。

## 网格与页面框架

画布 16:9（13.333 × 7.5 in），左右边距 0.65 in。

- **页眉区**：左上是陶土色的学术栏目名称（如“研究背景”），下面是衬线结论式标题（一行为佳，最多两行）；右上是进度条“研究背景 · 方法框架 · 方法创新 · 实验结果”，当前项陶土色加粗。
- **正文区**：标题下约 0.35 in 起，到 6.72 in 止。并排栏目顶端对齐，底边尽量落在同一条线上。
- **页脚区**：7.0 in 处一条通栏细线，左侧出处，右侧衬线页码。
- **标题页**：左侧约 60% 放文字（页眉、题名、原题、作者、核心想法），右侧浅色块上放论文首页截图（细描边 + 柔和投影），下方注明“原文首页 · 来源”。

## 组件

- **叙事箭头**（陶土色）连接论证步骤，如“场景 → 前作 → 缺口”“以往 → 本文”；**流程箭头**（灰色）连接方法中的数据流。两种箭头不要混用。
- **流程卡片**：白底、细描边、小圆角，左上是陶土色编号圆点；关键步骤用陶土色描边加浅陶土底。卡片内写“名称 + 输入/操作/输出”。
- **前作条目**：左侧石板蓝竖线，名称加粗并附小号引用，下面说明“进展 / 不足”，不足限定具体任务或条件。
- **强调块**：待解决问题、本文改变用 clay_tint 底色块；例子、公式、边界用 panel 色块。
- **表格**：三线表（表头上粗线、表头下细线、表尾粗线），行间极细线；本文所在行用浅陶土底加陶土色粗体；数字居中，第一列左对齐，表头写指标方向。
- **图表**：横向条形图优先，直接标数值，隐藏数值轴和网格线；本文陶土色，其余灰色。
- **编号**：结论与创新用衬线的 `01 02 03`，陶土色。

## 布局判断

- 主证据占主要面积，解释紧贴对应部件，不在另一侧重复整段正文。
- 一页一个主问题，但可以有多个对象，只要它们回答同一个问题。
- 位置表达关系：时序、因果用从左到右，比较用并列同维度。不要连续多页套同一种“三个等宽卡片 + 总结横条”。
- 留白是设计的一部分；但大块无意义空白（如表格很短、左下角空着）说明内容分配失衡，应调整。多篇组会中不要反复利用大号页眉和总结横条消耗空间；尽可能让实际论文图、机制解释和核心数据成为视线中心。

## 图表与原图

- 按比较关系选图型：少量类别用条形或点图，连续变化用折线，分布用箱线或小提琴图；不因模板好看就用雷达图或 3D。
- 标注单位、坐标范围、指标方向和必要的样本说明；截断坐标、不同样本量或统计口径要明确写出。
- 不凭空补误差线、p 值或显著性；没有可信数值时保留原图，不从模糊截图猜数值重绘。
- 原论文图选关键面板并放大，保留坐标、图例、条件和出处；不得裁掉会改变结论的基线或条件。

## 图示

**组会架构图顺序：原论文总图 → 核心机制局部。** 初次讲模型先给作者原始总体 Figure（不是原创重绘的第一个流程框图），在原图外标出输入、训练、下游与主创新的位置；紧随其后用清楚的自绘网格/计算过程深入解释核心 Attention、Token 或损失。除非原图无法获取或严重不可读，第一张总览不要只剩简单模块卡片。参考 [journal-club-density-and-figures.md](journal-club-density-and-figures.md)。

**去制作痕迹**：在投影页首/主标题避免“原始方法论文”“据原文重绘”“完整模型”“本次讲解标注”“图解××”等自我说明。论文名、期刊、年份和图的必要出处仍应有；若避免把机制示意当数据，需要在**小图注**注明“示意，非实验数据”，不要删除科学上必要的来源标记。

**原图的重要内容不得被新加标注遮挡。** 优先图外标注和原编号；需要在图内留白加标签或轮廓高亮时，确认不覆盖文字、箭头、轴、图例、数据和模块，也不改变原图含义。细引线不得穿过关键内容。复杂论文图在单屏不可读时，局部裁剪、忠实重绘或拆为总览与放大图。不能以缩小原图换取固定的右侧文字栏。

**证据图与文字需对应。** 在结果页用真实数据图、读得清的原始实验面板或源数据重绘；与这张图不同的实验结果不能放到旁边假装由该图支持。色块和字体不得掩盖样本分组、置信区间、坐标、图例和基线。

方法图先给可辨认的输入、输出和主路径，再解释关键模块；训练与推断分区，分支在汇合处写明如何组合，反馈要写明反馈什么、改变哪一步。拟议方案用虚线或标签与已验证模块区分。相邻页沿用同一对象的名称、颜色和例子。生成式插图标明“示意”，关键文字、公式和数据用可编辑对象排版。

## 五秒检查与细节检查

先看五秒：能否找到这一页要回答的问题、主证据和结论？再细读：图例、基线、单位、引用、条件是否齐全且可读？“漂亮但不知道说明什么”和“完整但远处看不清”都要返工。
