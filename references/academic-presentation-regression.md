# 科研讲解质量回归

本案例用于更新技能或重构同类讲解时做抽查。两篇原始研究分别是 [Conditional Monge Gap](https://doi.org/10.1038/s42256-026-01242-8) 与 [Bringing the genetically minimal cell to life on a computer in 4D](https://doi.org/10.1016/j.cell.2026.02.009)。这里记录的是原文定位和验收问题。页号对应一次历史汇报，供定位问题，不要求其他汇报沿用。运行时核对原论文版本。

| 原页或范围 | 可复用的验收问题 | 原文定位 |
|---|---|---|
| 2–3 · CMonge 背景 | 是否从分开测得的对照与处理细胞解释无配对学习的后果，并说明关心处理组的整个分布？前作比较须区分给定条件的传输、已有的条件映射与本文扩展的目标 | 引言、Fig. 1、直接前作 |
| 4–5 · 架构 | 从原始总图能否跟踪细胞表示、条件编码、共享映射和输出，并区分训练监督与推理输入？自编码器和残差连接作为实现讲解，贡献归于将 Monge Gap 目标扩展到跨条件共享传输 | Fig. 1a–c、Architecture、Eq. 9 |
| 6 · 核心目标 | 示意代价能否回到实际目标？以原式说明同一网络在所有条件上优化的总目标、预测分布与实测目标的匹配项、Monge Gap 项及其权重。保留条件索引与求和，说明参考分布与预测分布。示意配对代价只解释其中一项 | Eqs. 5–8 |
| 7–8 · 两种留出 | 分开解释同药留剂量与整药留出。能否指出插值和外推的位置、映射与自编码器分别见过什么、结构与实测响应嵌入的信息差异？均值拟合度所评价的对象与 MMD 所评价的分布差异须分别解释，亚群恢复需要单独证据 | Tables 1–2、Fig. 4b–c、Methods 数据划分与自编码器 |
| 10–11 · 全细胞模型背景 | 观测到的丰度、位置、形态和真正要解释的现象是否区分？旧全细胞模型已经包含完整周期动力学，本文应突出完整周期中动态空间和多模块的持续耦合 | Introduction、Fig. 1、直接前作 |
| 12–14 · 动力学与几何 | 是否讲清常规求解器各自更新什么、哪些状态以何种时间关系交换、边界变化如何反馈？区分成像约束、分裂几何假设及由模拟得到的粒子分配 | Figs. 1–3、4C–D、STAR Methods |
| 15–16 · 实测与预测 | 群体复制起点与终点覆盖度比提供独立证据，其接近程度无法唯一反推各复制阶段时长。对子计数差的正负可抵消，须同时看离散度。模拟预测用相应标签，避免写成对子分配已得到实测验证 | Fig. 4A–B、Fig. 6、Results |
